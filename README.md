# 💰 Blind Auction

A simple **Blind Auction** program written in Python.  
Each participant enters their name and bid amount secretly.  
At the end, the program compares all bids and announces the highest bidder as the winner.

## ✨ Features
- Collects bids from multiple participants.
- Stores bids in a dictionary with names and amounts.
- Clears the screen between entries to keep bids hidden.
- Determines the highest bid and prints the winner.
